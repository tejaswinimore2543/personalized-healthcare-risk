# 🏥 Personalized Healthcare Risk Prediction

A Python-based healthcare risk prediction web application built using Streamlit. The project analyzes input features and predicts a healthcare risk level to help users understand potential risk categories through an interactive interface.

## 🚀 Features

- 🩺 Predict healthcare risk based on input features
- 📊 Display risk classification as Low, Medium, or High
- 📈 Visualize prediction results using charts
- 🎯 Show risk percentage based on the implemented prediction logic
- 🖥️ Interactive and user-friendly Streamlit dashboard
- 📋 Present results in an easy-to-understand format

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Web Framework:** Streamlit
- **Data Processing:** Pandas, NumPy
- **Machine Learning:** Scikit-learn
- **Data Visualization:** Matplotlib
- **Development Tools:** Jupyter Notebook, VS Code

## ⚙️ How to Run the Project

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd YOUR_REPOSITORY_FOLDER
```

### 2. Create and activate a virtual environment (optional)

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit application

```bash
streamlit run app.py
```

### 5. Open the application

Streamlit will display a local URL in the terminal, usually:

```text
http://localhost:8501
```

Open this URL in your browser to use the application.

## 🧠 How It Works

1. The user enters the required input information through the Streamlit interface.
2. The application processes the input features.
3. The implemented prediction logic or trained machine learning model generates a risk prediction.
4. The predicted risk is categorized as Low, Medium, or High.
5. The application displays the result using risk indicators and visualizations.

## 🎯 Project Objective

To develop an interactive healthcare risk prediction application that presents risk categories and prediction results in a simple, understandable format using Python, machine learning techniques, and Streamlit.
